Siapa bisa memindahkan uang di Titip?

Hanya dua pihak: pemilik nama penerima (untuk mengambil) dan pengirim asal (untuk menarik kembali sesudah tenggat). Kontrak Titip tidak punya pemilik, tidak punya tombol admin, dan tidak bisa menarik dana pengguna. Alamat registry Agent ID tidak bisa diganti sesudah deploy.
